# VoicePrompter — телесуфлёр с голосовым следованием (Этап 1)

Русский офлайн-телесуфлёр: дорожка движется, только когда вы читаете текст вслух.

## Сборка APK (без Android Studio)
1. Создайте публичный репозиторий на github.com.
2. Загрузите в него ВСЁ содержимое этой папки, включая скрытую папку `.github`
   (в Finder скрытые файлы показываются по Cmd+Shift+Точка).
3. Откройте вкладку Actions — сборка запустится автоматически
   (облако само скачает русскую модель Vosk и зашьёт её в APK).
4. После зелёной галочки скачайте артефакт VoicePrompter-APK,
   распакуйте zip — внутри app-debug.apk.
5. Установите APK на телефон/планшет (разрешите установку из неизвестных источников).

## Подсказка
Числа в сценарии лучше писать словами («двадцать пять», а не «25») —
так распознавание следует за голосом точнее.
